# Fit Life

[![language:language](https://img.shields.io/badge/language-Typesrcipt-blue)]()
[![framework:framework](https://img.shields.io/badge/language-Vue-green)]()

A modern, responsive personal trainer website built with Vue 3. 
Designed for trainers who want to showcase their services, attract clients, and allow online bookings—all with a clean, professional, and mobile-friendly layout.

### Previews
- [Preview home](previews/preview.png)

### Features

- **Responsive Design:** Looks great on desktop, tablet, and mobile.
- **Vue 3 + Composition API:** Modern, maintainable, and scalable codebase.
- **Tailwind CSS Styling:** Clean, modern, and customizable UI.
- **Reusable Components:** Sections like hero, services, testimonials, and forms are modular.
- **Smooth Navigation:** Scroll-to-section and sticky navigation menu.
- **Interactive Booking Form:** Clients can book sessions online (can integrate with third-party calendar API).
- **Real Images:** High-quality, authentic visuals for trainers, programs, and clients.
- **Testimonials Section:** Showcase client success stories with images and quotes.
- **Blog / Tips Section:** Optional section for fitness tips and articles.
- **SEO-Friendly & Fast Loading:** Optimized for search engines and performance.

### Sections

1. **Home / Hero:** Motivational headline, real hero image or video, call-to-action button.
2. **About:** Trainer bio, certifications, philosophy, and real photos.
3. **Services / Programs:** Training options (one-on-one, group, online), pricing, and images.
4. **Testimonials:** Client success stories with quotes and images.
5. **Schedule / Booking Form:** Interactive calendar or booking form for sessions.
6. **Blog / Tips (Optional):** Fitness articles with visuals.
7. **Contact:** Contact form, email, phone, and social links.

#### Tech Stack
- [Vue 3](https://vuejs.org/) + Composition API
- [Vite](https://vitejs.dev/) for fast development
- [Tailwind CSS](https://tailwindcss.com/) for styling
- Optional: Calendar API integration for bookings
